# Implemented scope and remaining limits

Phase 1 implements the requested assessment knowledge base, Markdown/JSON ingestion, strict schemas, source hashing, lifecycle history, optimistic update conflicts, restricted patches, explicit review snapshots, rollback, deterministic structured comparisons, Quarto publishing, nine fixed sections, evidence drilldowns, responsive themes, exports and automated tests.

Research interpretation is intentionally performed by a human or an external agent. The module does not autonomously extract facts from arbitrary prose, verify vendor claims, or validate the truth of an analyst's reviewed/validated label. Evidence verification is asserted by the named reviewer; the software checks consistency and provenance. No real migration compatibility conclusions should be drawn from the synthetic samples.

Application approval has no authentication or multi-user authorization. The lock is for one local filesystem; this is not a collaborative server. Snapshots/revisions are immutable through the API, but a filesystem owner can edit/delete files. SHA-256 detects state changes, not malicious re-signing. Use Git/backups and restricted filesystem roles if required. The app does not execute or isolate external AI agents.

Only the documented JSON Patch subset is supported. YAML aliases/anchors, oversized Markdown (>2 MB/file), symlinks and traversal paths are rejected. JSON stores full source content in every revision: this favors auditability and portability over large-estate storage efficiency. Broad browser history is embedded in the cumulative report; very large histories may need pagination or separate data assets in a future version.

Weekly automation is supplied as an explicit command for your existing OS scheduler. No background daemon, notification delivery, cloud publication, remote API or unattended AI invocation is included. Quarto is a required external publishing dependency. Browser Print/PDF works and is tested; a dedicated PDF publishing pipeline is deferred.

Metrics use planned scope weights, not guessed completion percentages. Inconclusive investigations count as examined, so high coverage may coexist with low readiness. Estimate ranges are displayed independently with assumptions; calibrated forecasting, ROI, NPV, currency normalization and Monte Carlo analysis are deferred. Missing economic evidence stays Unknown.

Visual comparison is verified against the supplied Linux Chromium baseline. Cross-platform font/rendering differences may need a reviewed baseline. Keyboard navigation, modal behavior and responsive overflow are tested, but there is no claim of a complete accessibility certification.
